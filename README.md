mend is one patch tool for every AI edit format: it reads a patch in unified diff, SEARCH/REPLACE, V4A or JSON tool-call form, finds the lines to change at the first of three matching tiers (exact, trailing-whitespace-insensitive, fully whitespace-insensitive), and writes every change or none at all.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
